<h2>🔭 Featured Projects</h2>

<h3>
  <a href="https://github.com/AreebEhsan/Research-Assistant-Extension">
    Research Assistant Extension
  </a>
</h3>

<p>
  A two-tier AI research assistant built with <strong>Spring Boot</strong> and a 
  <strong>Chrome Extension</strong>. Users can highlight text on any webpage, send it to a Java backend, 
  generate AI-powered summaries through Gemini, and save useful notes directly from the browser.
</p>

<p>
  <strong>Tech:</strong> Java, Spring Boot, Gemini API, WebClient, Jackson, Lombok, Chrome Extension MV3, JavaScript
</p>

<h3>
  <a href="https://github.com/AreebEhsan/RAG-LLM-Applications">
    RAG-LLM Applications
  </a>
</h3>

<p>
  A suite of retrieval-augmented generation applications for website and PDF question answering. 
  Includes document loading, chunking, embeddings, vector search, and grounded responses using 
  LangChain, FAISS/Chroma, Streamlit, and PDF processing tools.
</p>

<p>
  <strong>Tech:</strong> Python, LangChain, FAISS, Chroma, Streamlit, PyPDF2, OpenAI/Gemini APIs
</p>

<h3>
  <a href="https://github.com/AreebEhsan/Developer-Tools-Research-LLM-Agent">

  </a>

<p>

<p>
